# Project: NextStep AI

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS
- React Query
- Axios
- Recharts

## Rules
- Use TypeScript only
- Use reusable components
- Keep components inside src/components
- Use services for API calls
- Follow responsive design
- Use maximum 3 primary colors
- No dummy content
- Maintain clean UI

## Project Goal
AI Career Assistant platform.

Features:
- Authentication
- Career Profile
- AI Career Roadmap
- AI Recommendation
- Dashboard Analytics
