# 🚀 NextStep AI – AI-Powered Career Guidance Platform

NextStep AI is a modern full-stack AI-powered career guidance platform that helps users discover suitable career paths, receive personalized AI career recommendations, and generate structured learning roadmaps based on their skills, interests, education, and experience.

Built with Next.js, Express.js, MongoDB, TypeScript, and Groq's Llama 3.3 70B Versatile model, the platform delivers an intelligent and interactive career planning experience through a clean, responsive, and professional user interface.
